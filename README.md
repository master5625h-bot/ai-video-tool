# Editor Engine

Free public AI video generator: text prompt (Hindi/English) -> 3-5 sec AI video, download/share.

- Frontend: static site, GitHub Pages (`master5625h-bot.github.io/editor-engine/`)
- Backend: Hugging Face Space (Gradio API) - set in `app.js` CONFIG.space
- Rate limit: 1 video per user per 10 min (client-side)
- Rs 0 budget stack

## Rename
Site name lives in `index.html` (title + h1). Repo rename = Settings -> Rename, Pages URL updates automatically.
